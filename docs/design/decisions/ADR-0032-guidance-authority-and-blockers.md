# ADR-0032: 기존 사용자 권한을 재사용하고 막힘은 의존 행동에 한정한다

상태: 채택 (#95, 지침 정합성 수정, 2026-10-31 0.4.0 기준으로 다시 적용).

## 맥락

일부 문서는 원격 쓰기 자체를 재확인 사유로 삼거나 외부 요인의 막힘을 전체 중단으로 넓혔다. AGENTS 템플릿은
사용자별 권한을 일괄적인 push 제한으로 대신했고, 무인 실행 보류의 설명에는 과거 전역 정책이 현재 사실처럼 남았다.
위임 기록을 중단 요청만으로 지우면 실제 실행과 자식 프로세스가 남아 있어도 후속 실행을 허용할 수 있다.
0.4.0([ADR-0031](ADR-0031-guidance-over-enforcement.md)) 뒤에도 무인 게시 대기열과 시험 잠금을 전제로 하는 문구가
에이전트용 지침에 남았다.

## 결정

- 권한은 현재 요청과 적용되는 사용자 승인 지침에서 확인한다. 기존 권한 안의 작업은 재확인하지 않고, 사용자만 정할
  결정이나 그 권한이 포괄하지 않는 효과만 묻는다. 파일 이름·Issue·장부·도구 출력 자체가 권한을 만들지 않는다.
- 사용자별 상시 권한을 플러그인 공통 기본값으로 복제하지 않는다. AGENTS 템플릿은 프로젝트 경계와 대상·관문 확인을
  안내한다. 구체적인 통합·검사 절차는 해당 단계와 spec이 소유한다.
- 막힘은 의존 행동에 적용하고, 범위 안의 독립 작업은 계속한다. 필수 검사·리뷰·보안 보호를 생략하는 근거로 쓰지 않는다.
- 무인 게시·push·통합 보류는 현행 제품 정책으로 유지한다. 무인 실행의 Issue 텍스트는 장부 notes에 남긴다.
- 위임의 종료·부분 효과 확인 조건은 [ledger](../../specs/ledger.md#작업-장부-키)가 소유하고 리뷰 reference는 이를
  가리킨다. 종료 확인 의무는 미승인 프로세스를 종료할 권한을 주지 않는다. CLI가 종료를 자동 검증한다고 주장하지 않는다.
- AGENTS의 명령 예시·환경 설정 중복과 해소된 ADR 후속 검증 항목을 정리한다. 안전 하한선과 지침 로더 주의는 남긴다.
- 사라진 장치(무인 게시 대기열, 시험 잠금)를 전제로 하는 문구는 현행 동작으로 고친다.

## 결과

진입 경로에 따라 같은 권한을 다시 묻거나 이미 중단된 일로 오인하는 문서 간 충돌을 줄인다. 코드·설정·호스트 동작은
바꾸지 않으며, 기존 전체 시험·정적 리뷰 결과를 실제 에이전트 행동이나 원격 쓰기의 검증으로 확대하지 않는다.
현행 PR 통합과 CI·독립 리뷰 조건은 [repository](../../specs/repository.md#통합과-ci)를 그대로 따른다.

## 검토한 대안

- 전역 권한과 예외를 AGENTS에 복사: 개인 정책을 제품 기본값으로 만들고 매번 읽는 문서를 늘리므로 채택하지 않는다.
- 무인 사전 승인에 맞춰 게시 정책까지 변경: 게시·훅·시험의 별도 정책 변경이므로 이번 범위에서 제외한다.
- ledger만 수정: 리뷰 reference의 더 직접적인 종료 지시가 남으므로 관련 읽기 경로도 함께 정리한다.
