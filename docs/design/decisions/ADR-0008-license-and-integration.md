# ADR-0008: Apache-2.0과 push-on-request

상태: 채택 (사용자 결정)

## 맥락

저장소는 공개다. Apache-2.0(공식 플러그인)과 MIT(superpowers, ponytail) 파일을 복사하고 고쳐서 배포할 예정이다.
개인용 플러그인이라 PR 리뷰를 거칠 다른 사람이 없다.

## 결정

- 저장소 라이선스는 Apache-2.0이다. 저작권 고지는 `NOTICE`, 출처 기록은 `SOURCES.md`에 둔다.
- 이 저장소의 통합 방식은 `push-on-request`다. 사용자가 지시할 때 `main`에 직접 push하고, PR은 쓰지 않는다.

## 결과

- 고친 Apache-2.0 파일에는 변경 사실을 표시한다. MIT 라이선스 원문은 `LICENSES/`에 둔다.
- 사용자의 개인 스킬을 이 저장소로 옮기면 Apache-2.0으로 공개된다. 옮기기 전에 공개 여부를 확인한다.
- 리뷰는 PR이 아니라 devflow의 최종 리뷰 단계와 체크포인트에 남는다.

## 검토한 대안

- MIT: 더 짧지만 특허 조항이 없고, 가져올 원본 대부분과 라이선스가 다르다.
- `pr-ci`: 혼자 쓰는 저장소에서는 절차 비용만 늘어난다.
