# Completion

Apply [rules](../SKILL.md). Verify start record or establish repo, linked Issues/milestones, criteria, closure gate and tracker authority.

PR prep: verify full/partial scope and platform closing links, including commits. Non-closing links protect pending post-merge/release gates; autoclosure cannot skip them. Milestone versions grant no release work. Approved local-only work verifies installation/artifact identity at agreed gate, not invented integration.

After required validation reconcile each Issue's criteria/dependencies/findings/linked work; record evidence/remnants. Close only satisfied Issues as completed with reviewed evidence; others stay open with next action. Merge/checkboxes/tracker state/successors/empty backlog alone cannot prove completion. Never weaken criteria to close; rescope/deferral needs authorized disposition, retaining blockers.

Before creating successors for remnants, search open/closed matches: reuse open; justify new or reopen. Successors need problem/evidence, scope/observable criteria, dependencies, source Issue/PR, next action, confirmed owner/priority or unknowns. Link both ways within authority. No invented backlog/private logs/unauthorized assignments/deadlines. Registration grants no implementation or next cycle.

Verify required successors' existence/scope before source closure. Failed/uncertain transfer keeps draft/incomplete status; unmet original criteria keep source open. Unrelated follow-ups cannot delay completed Issues. Verify closed items without duplicate closure/comments; report premature autoclosure on failed gates and reopen the Issue.

For linked in-scope milestones paginate all Issues/PRs and check own criteria/dependencies. Close only satisfied; 0 open/100% or one PR cannot excuse moved/cancelled/unverified work. Invent none.

Report closed/open/unverified Issues/milestones, successor links and pending writes.
