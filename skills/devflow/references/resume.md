# Resume

Done when target/authority/proof/next agree.

## Reconcile
Report `buildReason`. Hold on conflict/stale proof/missing inputs. Reuse trusted proof if command/assertions/inputs/conditions match. Report denials; retry after capability changes.
### Tracked progress
Hold competing writes until handoff; `note`, reread. Mark unknowns. Ledger-only task moves/post-ship.
## Recovery and parallel work
Timeout ≠ exit or kill authority. Before retry prove process tree exit; reconcile writes/commits/checks/worktrees. Keep reservations/uncertain or rejected effects; continue independent work. Apply owned results once at current base/plan; interface changes void affected proof. Then `running <issue> done <label>`.
## Handoff
Finish checks/commits/records/workers. Handoff target/proof/open effects/next. Owner only: `release <issue>` last.
## Unattended work
Explicit: owner/open task, no blockers/decisions/workers. `mode <issue> autonomous < reason`; return `mode <issue> interactive < reason` (stdin). Approve new intent before criteria edits.
