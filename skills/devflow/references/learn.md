# Learn

Runs only when there is a lesson: something that went wrong twice, cost real time, or was measured. Done when each
lesson sits in one place and nothing it replaces is left behind.

- Place it by [Learn and memory](../../../docs/specs/lifecycle.md#learn-and-memory). A rule a test can check goes into a test, and
  its prose leaves AGENTS.md; a safety floor stays as prose.
- When the place is a file an agent loads (AGENTS.md, a skill, an agent definition), follow
  [Text agents read](../../../docs/specs/documents.md#text-agents-read); AGENTS.md has a one-page budget, so a new line usually displaces an old one.
- A lesson about one machine stays in private notes; one about the owner's habits across projects is proposed for the
  user's global instructions, not written there.
- Keep the story behind a lesson in the Issue checkpoint and git. Update the project's `docs/design/current-decisions.md` only when the lasting choice or its reason changes.
