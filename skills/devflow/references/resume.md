# Resume

Done when target, authority, proof and next action agree.

## Reconcile
Verify workspace/hashes/revision/dirty/ignored inputs. Report `buildReason`. Hold dependents on conflicts, stale proof or missing inputs. Reuse trusted proof on matching command/assertions/inputs/conditions. Rerun affected/required checks. Report denials; retry after capability changes.

### Tracked progress
Issue owns intent/stage, ledger tasks/blockers, plan scope/Git. Mark unknowns. Hold competing state writes until handoff. Append `note` and reread. Keep proof private. Task moves/post-ship: ledger only.

## Recovery and parallel work
Timeout alone proves no exit, grants no kill. Verify process tree exit and reconcile writes/commits/checks/worktrees before retry. Keep uncertain/rejected effects and reservations. Continue independent work. Apply owned results once against current base/plan. Interface changes void affected proof. Then `running <issue> done <label>`.

## Handoff
Finish checks/commits/records/workers. Pass target/proof/open effects/next action. Keep reservations. Confirmed owner runs `release <issue>` last.

## Unattended work
Explicit intent only: `mode <issue> autonomous < reason`, return with `mode <issue> interactive < reason`. Pass reason on stdin. Need owner/open task, no blockers/decisions/workers. Log deferred Issue writes/pushes/integration. Approve new intent before criteria edits.
