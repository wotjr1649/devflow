# ADR-0007: 서브에이전트의 질문은 멈추고 재개한다

상태: 채택 (사용자 결정)

## 맥락

- Claude Code는 서브에이전트에서 `AskUserQuestion`을 제거한다.
- `SendMessage`의 수신자 목록에는 `main`이 들어가지만, 메시지를 보낸 뒤 답을 기다리는 동작은 문서에 없다.
- 재개된 서브에이전트는 대화 기록 전체와 모델 설정을 유지한다.
- Codex는 같은 에이전트에 후속 작업을 보낼 수 있다(OpenAI 멀티에이전트 기본 기능).

## 결정

- 지시서 범위 밖의 결정이 필요하면 서브에이전트는 `NEEDS_DECISION`으로 종료한다.
- 메인이 결정하고 같은 에이전트를 재개한다.
- 실행 중 메시지는 알림용으로만 쓴다.
- 절차는 [orchestration](../../specs/orchestration.md#서브에이전트의-질문)이 정한다.

## 결과

- 결정권이 메인 한 곳에 모인다.
- 사용자 답을 기다리는 시간이 서브에이전트 캐시 TTL을 넘으면 재개할 때 캐시를 다시 쓴다.
- Codex의 재개 동작은 파일럿에서 확인한다.

## 검토한 대안

실행 중 동기식 질문(`SendMessage`나 `wait_agent`로 답을 기다리며 계속): 문서로 보장되지 않는다.
