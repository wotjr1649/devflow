### Tracked progress

## Recovery and parallel work
Timeout ≠ exit/kill authority. Before retry: prove tree exit, reconcile writes/commits/checks/worktrees. Keep reservations/uncertain/rejected effects; continue independent work. Apply owned results once at current base/plan; interface drift voids affected proof. Then `running <issue> done <label>`.
## Handoff
Finish checks/commits/records/workers. Pass target/proof/open effects/next. Owner: `release <issue>` last.
## Unattended work
Explicit intent; owner/open task; no blockers/decisions/workers. `mode <issue> autonomous < reason` → `mode <issue> interactive < reason` (stdin). Approve new intent before criteria edits.
