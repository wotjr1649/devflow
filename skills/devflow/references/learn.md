# Learn

Runs only when there is a lesson: something that went wrong twice, cost real time, or was measured. Done when each
lesson sits in one place and nothing it replaces is left behind.

- Place it by [회고와 기억](../../../docs/specs/lifecycle.md#회고와-기억). A rule a machine can check goes into a hook,
  a test or a doctor check, and its prose leaves AGENTS.md.
- When the place is a file an agent loads (AGENTS.md, a skill, an agent definition), call `writing-for-agents` and
  run `devflow-doctor` afterwards; AGENTS.md has a one-page budget, so a new line usually displaces an old one.
- A lesson about one machine stays in private notes; one about the owner's habits across projects is proposed for the
  user's global instructions, not written there.
- The story behind a lesson belongs in the commit message or the decision record, not in the rule.
