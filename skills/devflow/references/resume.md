# Resume

Done when target, authority, evidence and the next action agree.

## Reconcile

Status is read-only. Verify repository, worktree, branch, base/head and dirty/ignored inputs. Hold conflicts, stale proof and missing inputs. Start approved unblocked steps. Retry only permitted parts of refused calls. Reuse trusted runs only if allowed and command, assertions, inputs and conditions match. Rerun affected or required proof.

### Tracked progress

Issue owns intent/stage, ledger tasks and blockers, plan scope and Git applicability. Unknown stays unknown. Hold competing state/key writes until handoff. Append `note` and reread. Task moves and post-ship cleanup/learning are ledger-only.

## Recovery and parallel work

Timeout alone proves no exit or authority to terminate. Confirm process/children exited and reconcile writes, commits, checks and worktrees before retry. Preserve uncertain or rejected effects and reservations. Continue independent work. Apply owned results once against current base/plan. Changed interfaces invalidate affected proof. Run `running <issue> done <label>` only after recovery.

## Handoff

Finish checks, commits, records and workers. Preserve unresolved reservations. Hand off links, effects and next action within 500 tokens. Use `release <issue>` last except a Claude child inheriting `CODEX_THREAD_ID`. The user runs `/clear`.

## Unattended work

Use `mode <issue>` on explicit unattended intent. Claim unattended work or switch interactive when the user returns. Proceed only as owner with open task and no decisions, blockers or workers. Defer Issue writes, pushes and integration in notes. Approve new intent before updating criteria.
