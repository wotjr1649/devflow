# Resume

Done when target/authority/proof/next agree.

Report `buildReason`; hold conflicts/stale proof/missing inputs. Reuse trusted proof matching command/assertions/inputs/conditions. Report denials; retry on capability change.
### Tracked progress
Mark unknowns. Hold competing writes until handoff; `note`, reread. Task moves/post-ship: ledger only.
## Recovery and parallel work
Timeout ≠ exit or kill authority. Before retry prove tree exit; reconcile writes/commits/checks/worktrees. Keep reservations/uncertain or rejected effects; continue independent work. Apply owned results once at current base/plan; interface changes void affected proof. Then `running <issue> done <label>`.
## Handoff
Finish checks/commits/records/workers. Pass target/proof/open effects/next. Owner: `release <issue>` last.
## Unattended work
Explicit intent; owner/open task, no blockers/decisions/workers. `mode <issue> autonomous < reason`; return `mode <issue> interactive < reason` (stdin). Approve new intent before criteria edits.
