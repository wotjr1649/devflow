# Resume

Done when target/authority/proof/next agree.

Report `buildReason`/denials; hold conflicts/stale proof/missing inputs. Reuse trusted proof matching command/assertions/inputs/conditions. Retry on capability change.
### Tracked progress
Mark unknowns; hold competing writes until handoff. `note`, reread. Task moves/post-ship: ledger only.
## Recovery
Timeout ≠ exit/kill authority. Retry: prove tree exit; reconcile writes/commits/checks/worktrees. Keep reservations/uncertain/rejected effects; proceed independently. Apply owned results once at current base/plan; interface drift voids affected proof. Then `running <issue> done <label>`.
## Handoff
Finish checks/commits/records/workers. Pass target/proof/attempts/open effects/next. Owner: `release <issue>` last.
## Unattended work
Explicit intent, owner/open task, no blockers/decisions/workers. `mode <issue> autonomous < reason` → `mode <issue> interactive < reason` (stdin). Approve new intent before criteria edits.
